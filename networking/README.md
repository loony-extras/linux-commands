# Networking

Interfaces, routing, DNS, firewalls, SSH and HTTP clients.

| Program | Description |
|---------|-------------|
| [ip](ip/) | Interface configuration, netplan and routing tables |
| [dns](dns/) | Resolver and DNS server setup |
| [firewall](firewall/) | UFW, nftables and iptables |
| [ssh](ssh/) | Remote access, file transfer and SSH hardening |
| [diagnostics](diagnostics/) | ss, netstat, tcpdump and connectivity debugging |
| [curl](curl/) | HTTP client and data transfer |
| [wget](wget/) | File downloader |
